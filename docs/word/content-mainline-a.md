# 主线 A · 单词讲解内容方案

> 配合渠道：**微信视频号 → 小程序**；**抖音 → Web**（`https://www.arelore.com/word`）。  
> 形态：15～25 秒短视频，场景/拆词讲解，**不是功能广告**；片尾轻 CTA，导流放简介与置顶评论。  
> 产量搭档见 [主线 B](./content-mainline-b.md)；周节奏见 [生产手册](./content-production.md)。

---

## 0. 渠道分流（建议采用）

| 平台 | 个人介绍 / 主页链接 | 理由 |
|------|---------------------|------|
| 微信视频号 | 挂 **小程序（背单词）** | 同生态一跳到达；微信用户习惯小程序；分享链路完整 |
| 抖音 | 挂 **Web**（`www.arelore.com/word` + 建议带 UTM） | 抖音外链能力有限时，简介/主页链网页最稳；也利于 SEO 品牌检索 |

**补充约定**

- 视频号每条：**置顶评论**再写一次「点头像进小程序 · 背单词」  
- 抖音每条：置顶「网页版 arelore.com/word」+ 主页链接；若有抖音小程序/站内能力再另开，不替代 Web  
- 同一条成片可两边发，**只改片尾 1 句 CTA 字幕**（「微信搜背单词」vs「打开 arelore.com/word」）  
- UTM 示例：`/word?utm_source=douyin&utm_medium=video&utm_campaign=compound_word`

结论：**这个分流合理，建议就这么定。** 视频号硬链 Web 跳出感强；抖音硬推小程序路径长且常被限。

## 1. 统一片型（所有词类共用）

| 秒数 | 画面 / 声音 | 字幕要点 |
|------|-------------|----------|
| 0～3 | 强钩子：场景或「很多人记错」 | 问句或反常识一句 |
| 3～15 | 拆解：部件 → 合成/派生逻辑 → 完整词 | 大号展示词形，可读清 |
| 15～20 | 一句例句或听写提示（可读可听） | 「听写时注意…」 |
| 20～25 | 淡 CTA | 视频号：「头像进小程序」；抖音：「主页进网页版」 |

**禁忌（公开片）**：摸鱼、完整 App 录屏、长卖点列表、少儿卡通人设。

**产能**：先用「静图/轻动效 + 云 TTS + 剪映模板」；需要氛围再对单条上 Seedance，不必每条都生成长视频。

**系列命名（便于追更）**

- `合成词 · 第 N 期`  
- `派生词 · 第 N 期`  
- `易混词 · 第 N 期`  
- …（见下文各类）

## 2. 按词类怎么做

### 2.1 合成词（Compound）——优先做，最好懂、最好搜

**逻辑**：A + B → AB，用生活场景解释「为什么拼在一起」。

| 项目 | 建议 |
|------|------|
| 钩子 | 「冰淇淋不是冰奶油？」「blackboard 为什么是黑板不是黑木板？」 |
| 结构 | 出 A 场景 → 出 B 场景 → 叠在一起出 AB → 一句中文释义 |
| 画面 | 两段短场景（或两张图）+ 中间「+」动画 + 成词大字幕 |
| 听写钩子 | 「听写时按两截来记，别整词死背」 |
| 选题池示例 | ice+cream, black+board, sun+flower, note+book, rain+coat, tooth+brush, week+end, green+house, fire+fly, soft+ware |

**成片脚本示例（ice-cream，约 20s）**

1. 「ice 是冰，cream 是奶油——拼一起不是冰奶油。」  
2. 画面：冰块 → 奶油/甜筒 → 合成 ice-cream。  
3. 「是冰淇淋。听写注意中间有没有连字符，看词书怎么写。」  
4. CTA 分端改一句。

**系列节奏**：每周 3 条合成词即可撑起账号前两周。

---

### 2.2 派生词（Affix：前缀 / 后缀）——备考党最爱，利于「一类讲透」

**逻辑**：词根不变，前缀改「方向/否定」，后缀改「词性」。

| 项目 | 建议 |
|------|------|
| 钩子 | 「一个 un-，否定全家桶」「-tion 一加，动词变名词」 |
| 结构 | 先给熟悉的词根 → 加缀 → 新词释义 → **同缀再闪 2 个词**（强化系列感） |
| 画面 | 词根卡片 + 前缀/后缀「积木扣上」；少用复杂剧情 |
| 听写钩子 | 「听写先抓词根，再补前后缀字母」 |
| 选题池 · 前缀 | un-happy, re-write, pre-view, dis-agree, mis-take, inter-national, over-load, under-stand（慎：有的已不透明） |
| 选题池 · 后缀 | care-ful / care-less, act-ion, happy-ness, teach-er, invent-or, friend-ly, modern-ize |

**系列拆法（避免乱）**

- 一周只打一个缀：如「本周全是 un-」→ 完播与关注更高  
- 片头固定 BGM/片头花字：「派生词 · un- 03」

**脚本骨架（un- + happy）**

1. 「happy 开心；前面加个 un-。」  
2. 「un- 多表示『不』→ unhappy 不开心。」  
3. 闪过：unfair / unclear（0.8s 一个）。  
4. 「四六级爱考这种。听写别漏那个 n。」  
5. CTA。

---

### 2.3 易混词 / 形近音近（Confusable）——评论区互动强

**逻辑**：两个词并排，讲「差在哪一个字母 / 哪一个音」。

| 项目 | 建议 |
|------|------|
| 钩子 | 「affect 和 effect，到底谁是动词？」 |
| 结构 | 左词右词对比 → 一句口诀 → 各给半句例句 |
| 画面 | 分屏或左右滑；错误用法打 ✕ 再改正 |
| 听写钩子 | 「听写只靠读音容易混，看词形差哪几个字母」 |
| 选题池 | affect/effect, principal/principle, accept/except, advise/advice, desert/dessert, quite/quiet, lose/loose, station/ary vs stationery |

**适合**：考季加更；评论区置「你还想看哪一对」。

---

### 2.4 一词多义（Polysemy）——贴合「看词识意」

**逻辑**：同一个拼写，两个场景两套意思。

| 项目 | 建议 |
|------|------|
| 钩子 | 「book 不只是书」「light 又是灯又是轻」 |
| 结构 | 场景 A 义项 1 → 场景 B 义项 2 → 「同一个词」 |
| 画面 | 两段生活镜头切换（Seedance 适合） |
| 听写钩子 | 「听写拼写一样；认词义要看场景」 |
| 选题池 | book, light, watch, bank, park, mean, interest, present, match, spring |

**和产品**：引导「别只会第一个释义」——对应词书多义条目（有则更好）。

---

### 2.5 缩略与合成缩写（Blend / Acronym 轻量）——娱乐向，控量

| 项目 | 建议 |
|------|------|
| 例子 | brunch=breakfast+lunch, smog=smoke+fog, NATO 等（专名慎用政治向） |
| 用法 | 每周最多 1 条调剂；不要做成账号主人格 |
| 钩子 | 「两个词各咬一口，拼出新词」 |

---

### 2.6 短语动词（Phrasal，可选辅线）

更接近「短语动画」，主线 A 里**降级为「动词 + 小品词」拆解**，控制成本：

- 例：look up / look after / give up  
- 结构：同一动词 + 不同小品词 → 意思全变  
- 不要拍完整「看病情景剧」，只做黑板式拆解 + 一个生活静图即可

## 4. 标题 / 封面 / 导流文案

**标题（带词，利于搜）**

- `ice + cream = 冰淇淋？合成词这样记`  
- `un- 否定前缀｜unhappy 为什么不是「很开心」`  
- `affect 和 effect 一眼分清｜听写别混`

**封面**

- 大词形 + 一个「+」或「vs」；字少、对比强；避免小字说明书。

**置顶评论**

- 视频号：`点头像进小程序「背单词」，词书里继续听写这一组`  
- 抖音：`网页版 www.arelore.com/word （主页也可点）`

**个人介绍**

- 视频号：一句话定位「碎片时间听写 / 合成词·派生词短讲解」+ 小程序链接  
- 抖音：同定位 + Web 链接（带 UTM）

## 5. 和产品能力的对齐（内容别跑偏）

| 内容类型 | 观众带走的习惯 | 产品承接 |
|----------|----------------|----------|
| 合成 / 派生 | 按部件记、按缀记 | 词书学习 + 听写 |
| 易混 | 盯词形差异 | 听写模式 |
| 多义 | 结合场景选义 | 看词识意 |
| 片中「听一听」 | 戴耳机跟读 | 听力/听词模式 |

片中可说「听写时…」「戴耳机听一遍…」，**不要说「打开某某 App 会员」**。

---

## 6. 验收（两周后看）

1. 哪类完播更高（合成 vs 派生 vs 易混）  
2. 评论是否出现「小程序在哪 / 网页是啥」  
3. 视频号小程序打开、抖音 Web 落地（UTM）是否有点击  

用结果调整下周比例，而不是凭感觉加少儿或毒鸡汤线。
