# 内容生产手册（A + B）

把 [主线 A](./content-mainline-a.md) 与 [主线 B](./content-mainline-b.md) 收成可执行节奏与检查清单。

---

## 1. 账号与渠道（锁定）

| 项 | 约定 |
|----|------|
| 人设 | 碎片时间听力 / 听写；成人向；不提摸鱼 |
| 视频号 | 简介 → **小程序「背单词」**；每条置顶再导一次 |
| 抖音 | 简介 → **Web** + UTM；每条置顶网页 |
| 同片分发 | 改片尾 CTA + 置顶即可，不必两套剧情 |

---

## 2. 每周节奏（默认）

| | 一 | 二 | 三 | 四 | 五 | 六 | 日 |
|--|----|----|----|----|----|----|-----|
| B 朗读条 | ✓ | ✓ | ✓ | ✓ | ✓ | 挑战可选 | 休或复盘 |
| A 讲解 | ✓ | | ✓ | | ✓ | | |

- 周产量目标：约 **5 条 B + 3 条 A**（可先降到 3B+2A 冷启动）  
- A 内部比例：合成 40% / 派生 30% / 易混 15% / 多义 15%  
- 派生词：**同一周尽量同一词缀**（如整周 un-）

---

## 3. 批量备料（周日 1 小时）

1. 从词书/词表选出下周 A 用词 3 个 + B 用词 25～35 个（或 5 句精听）  
2. LLM 一次生成：标题、钩子、口播稿、中文义、封面大字  
3. 云 TTS 批量导出 mp3，按 `dayNN_word.mp3` 命名  
4. 选图或生成封面图，放入当周文件夹  
5. 剪映复制模板，占位素材拖入即可  

文件夹建议：

```
content-week-XX/
  scripts.md          # 口播与标题
  audio/
  covers/
  export/             # 成片；抖音/视频号可同文件
```

---

## 4. 发布检查清单（每条）

- [ ] 竖屏 1080×1920；片长符合片型（A≤25s 优先，B≤30s）  
- [ ] 英文关键词出现在**标题 + 封面**（利于搜）  
- [ ] 无「摸鱼」、无硬广口播、无敏感少儿定位  
- [ ] 片尾 CTA 与平台一致（小程序 vs Web）  
- [ ] 置顶评论已发  
- [ ] 抖音链接带 `utm_source=douyin&utm_campaign=...`  
- [ ] （可选）评论区预埋下期预告词，促关注  

---

## 5. Seedance / 重视频何时用

| 场景 | 是否用 |
|------|--------|
| 主线 B 日更 | **否**，静图足够 |
| 主线 A 合成词 / 多义需要「两个场景」 | **可选**，每条 1～2 段 3～5s 即可 |
| 封面动效、账号片头 2s | 可做一次循环复用 |
| 全片 Seedance 长镜头 | 不建议，贵且慢，不像讲解号 |

口播与字幕仍以剪映为准；AI 视频只补画面，不替代脚本结构。
