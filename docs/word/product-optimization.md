# 墨鱼背词优化建议（竞品痛点对照）

综合：DeepSeek 主流产品吐槽 + 本仓 [competitive-pain-points.md](./competitive-pain-points.md)。  
原则：**不要用竞品的「强项」硬刚（词库规模、原声影视库、社交打卡），去占他们被骂最狠、而你们已有苗头的缺口。**

你们已有：词书计划、看词识意 / 听词 / 听写、Web+小程序、释义 TTS、中性标签页。  
下文按优先级：P0 信任与主路径 → P1 差异化加深 → P2 体验与增长。

---

## 1. 竞品骂点 → 我们该避免 / 该加强

| 竞品被骂点 | 墨鱼背词应对（产品原则） |
|------------|--------------------------|
| 多邻国幽灵扣款、退款难 | **永不暗扣**；试用明示到期；支付与退款路径写清 |
| 多邻国慢、偏启蒙、应试弱 | 坚持**词书+计划**，不做空游戏连胜绑架 |
| 墨墨处处收费、上限羞辱 | 核心听词/听写**不卡额度**；付费放扩词书/高级音色等增值 |
| 墨墨助记擦边 | 助记/UGC **先审后上**或仅官方；公开内容禁低俗 |
| 墨墨纯文字枯燥 | 用「听」补趣味，而不是堆花哨游戏 |
| 百词斩记图不记词 | **默认验收用听写/听词**，看词识意勿做成四选一猜图 |
| 扇贝开屏广告劝退 | Web/小程序 **学习路径零开屏广告**（至少核心流程） |
| 扇贝界面臃肿 | 首页只做：词书进度 + 开背；口语听力外链别堆首页 |
| 不背数据统计扯皮 | 时长/个数 **可核对**（本地+服务端一致）；忌「偷偷涨分钟」 |
| 不背节奏拖、复习债 | 单轮要快；复习设**每日上限/债软着陆** |
| 沪江释义/音标错 | 词条质量 > 数量；多义至少覆盖常用义；TTS 抽检 |
| 有道复习无上限滚雪球 | 计划页明确「今日复习封顶」；断签可「只清债不学新」 |

## 2. 建议优化清单（按优先级）

### P0 · 信任与「真掌握」（对标扣款/假掌握/广告）

| # | 优化项 | 做什么 | 打谁的痛点 |
|---|--------|--------|------------|
| 1 | **听写作为掌握门禁（可选策略）** | 新学可用看词；「掌握/出队」建议至少过 1 次听写或听词闭环 | 百词斩假掌握、选择猜对 |
| 2 | **学习路径零广告** | 开背→学完全程无开屏/摇一摇；变现不进学习页 | 扇贝广告 |
| 3 | **付费边界白皮书** | 设置/关于写清：免费含什么、什么要钱；禁止「背到一半不能背」 | 墨墨上限、多邻国信任 |
| 4 | **数据可信** | 今日新学/复习/听写正确率口径统一；时长按实际播放或主动学时计，不虚增 | 不背数据背刺 |
| 5 | **词条质量抽检** | 音标、多义、TTS 抽检清单；错义可反馈一键报错 | 沪江/有道释义问题 |

### P1 · 差异化加深（对标听不见、写不出、盯屏累）

| # | 优化项 | 做什么 | 说明 |
|---|--------|--------|------|
| 6 | **听词模式「真少盯屏」** | 大按钮暂停/下一词；屏幕可暗/锁屏后仍播（能力范围内）；结束震动/提示 | 你们已有听词，做成「通勤可用」叙事 |
| 7 | **听写体验打磨** | 错字母即时反馈、可跳过难词进错词本、听写后自动进下一词节奏可控 | 已有听写，对标学校听写刚需 |
| 8 | **复习债软着陆** | 「今日复习上限」；断签回来可选：只复习 N 个 / 压缩债 / 先学新 | 不背高利贷、有道滚雪球 |
| 9 | **一轮要快** | 默认每组 5～10 词；听词单词流程压到可接受秒数；避免「一组要很久」 | 不背拖沓、多邻国慢 |
| 10 | **多义与易混** | 词条多义切换；学习中偶尔出「易混对比」轻提示（非长文） | 沪江单义、百词斩混淆 |
| 11 | **Web↔小程序进度一体** | 同账号词书进度同步；两端 CTA 互导已规划 | 小程序轻量 vs App 重 |

### P2 · 体验、合规与增长

| # | 优化项 | 做什么 |
|---|--------|--------|
| 12 | **断签不羞辱** | 连续天数可展示，断了不扣「人格」；不强制社交公开打卡 |
| 13 | **教材/考纲标签清晰** | 词书标明四六级/考研等；课内同步可后做，先把应试标签做准 |
| 14 | **举报与内容安全** | 若有用户助记：举报+人工；默认关 UGC 擦边 |
| 15 | **支付合规** | 订阅需二次确认、到期提醒、退款入口；忌试用转年费陷阱文案 |
| 16 | **掌握度可见** | 简单区分：见过 / 听对 / 写对；避免只有一个「认识」按钮 |
| 17 | **错词本+听写复习** | 听写错的词进错词本，可用「仅听写模式」清错词 | 
| 18 | **内容侧配合** | 短视频「听写揭晓/合成词」引流到小程序听写，产品承接要顺 |

## 3. 不建议现在卷的方向

| 方向 | 原因 |
|------|------|
| 对标墨墨「千亿算法」宣传 | 信任成本高，且用户骂的是收费不是算法不够 |
| 对标百词斩大图社交 | 假掌握陷阱 + 与听写人设冲突 |
| 对标不背百万影视原声 | 版权与成本高；你们用 TTS 听词已够差异 |
| 对标扇贝全家桶首页 | 易臃肿劝退 |
| 对标多邻国重度游戏化 | 应试党与上班摸鱼党都不买账；且有扣费舆情雷 |

## 4. 一句话产品定位（优化后更清晰）

**墨鱼背词 = 词书计划 + 耳朵练习 + 拼写验收**  
在别人比「谁词库更大、谁广告更多、谁会员更狠」时，你们比：**听得到、写得出、不坑钱、不打断。**

---

## 5. 建议落地顺序（约 4～6 周视角）

1. 复习上限 + 断签软着陆（防债）  
2. 听写/听词主路径体验（速度、错词本）  
3. 免费/付费边界与无广告学习页（信任）  
4. 数据口径与报错入口（可信）  
5. 多义/易混轻提示 + Web 小程序同步打磨  

内容运营（主线 A/B）与上述产品优化并行：视频负责把人带进「听写/听词」，产品负责让人留下且不踩竞品同款雷。
