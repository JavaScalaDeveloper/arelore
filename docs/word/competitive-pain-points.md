# 背单词产品痛点调研（App / 小程序 / 网站）

> 依据公开横评（少数派、网易、南都、知乎专栏等）、用户讨论（豆瓣、应用商店评论、Reddit）与常见投诉归纳，**非内部数据**。  
> 目的：找「认词 ≠ 会用 / 会听 / 会拼」缝隙，对照墨鱼背词（听词、听写、少盯屏）的差异化。

---

## 1. 行业共性痛点（几乎每家都踩）

| 痛点 | 表现 | 用户原话/现象 |
|------|------|----------------|
| **认词 ≠ 会用** | 刷完词库阅读/写作仍卡壳 | 「词认识，句子写不出来」 |
| **认词 ≠ 会听会拼** | 选择题/看图过关，听写空白 | 「听写时还是写不出」 |
| **复习债雪球** | 断几天后待复习爆炸，直接弃用 | 「电子债主 / 高利贷」 |
| **坚持靠意志** | 再强的算法也要你主动打开 | 「工具都不差，差的是打不打开」 |
| **付费墙挫败感** | 背到一半卡额度/会员 | 删 App、投诉退款 |
| **虚假掌握** | 选项/图片线索猜对，实际未内化 | 「看选项就会，关掉就不会」 |
| **碎片场景不适配** | 必须盯屏点选，通勤/工位难用 | 上班族改用「闹钟磨耳朵」类产品 |
| **广告与打扰** | 开屏、弹窗、游戏化打断心流 | 百词斩等被点名广告偏多 |

## 2. 分产品痛点表

| 产品 | 形态 | 主打 | 主要痛点 | 对墨鱼背词的启示 |
|------|------|------|----------|------------------|
| **百词斩** | App | 图片联想、社交打卡、多题型 | ① 记图不记义，迁移到阅读失败 ② 广告偏多、包体大 ③ 例句/搭配偏弱 ④ 联想牵强、一词多义吃力 | 少依赖「猜选项/看图」；听写检验真掌握 |
| **墨墨背单词** | App | 算法复习、词库全、考研圈 | ① **单词上限付费**争议大 ② 界面偏旧 ③ 手动勾选词步骤繁 ④ 枯燥、清任务感 ⑤ 不解决听说写输出 ⑥ 权益/重置类投诉偶发 | 免费路径清晰；「听」补枯燥；别用额度卡死中段用户 |
| **不背单词** | App | 影视原声例句、极简 UI | ① 复习像「高利贷」，滚太大易弃 ② 选择题易假掌握 ③ 过例句耗时长、赶进度慢 ④ 应试/听写专项弱 ⑤ 部分词典/词根付费 ⑥ 课内同步弱 | 「随身听+听写」是其亮点方向——可做得更轻、更少债 |
| **扇贝单词** | App（生态） | 打卡、筛熟词、AI 规划、多 App 联动 | ① 词根/派生/AI 讲解多要会员 ② 例句相对少 ③ 断签社交压力反噬 ④ 功能杂、上手成本 ⑤ 单独用单词模块体验「中规中矩」 | Web/小程序做「轻量听写」比拼重生态更现实 |
| **沪江开心词场** | App | 多语种、词场 | 收费结构不清晰；学习深度口碑一般 | 定价透明 |
| **闯词** 等少儿向 | App | 游戏闯关、教材同步 | 高阶空白、玩法易腻、弹窗多；成人号勿碰 | 人设避开少儿 |
| **背单词花园** | App+**小程序** | 课本同步、拼读、轻养成 | 核心功能会员墙；试用短 | 小程序「即开即用」是优势——我们可对标顺滑 |
| **拓词 / 极光** 等 | App | 番茄钟、返现激励 | 激励短期有效；内容深度参差 | 激励别压过学习本身 |
| **欧路 / 有道等词典+生词本** | App/网站 | 查词、生词本复习 | 偏工具非整套「每日计划」；背词体验碎片 | 可做「计划+听写」完整环 |
| **Quizlet** | App/网站 | 自制卡片、课堂 | 基础学习强推订阅；广告/干扰；SRS 曾弱于 Anki；隐私默认公开 | Web 端免费核心路径要清楚 |
| **Anki** | 桌面/App | 最强 SRS | 上手陡、做卡累、复习量可压垮生活；易「只刷卡不浸泡」 | 降低配置成本；控制复习债 |
| **Duolingo** | App/网站 | 游戏化综合课 | 语法弱、背词/听力深度不够、连胜绑架；不像应试词书 | 别做成空游戏；词书目标要清晰 |
| **可可英语等听力站** | App | 海量听力 | 界面旧、广告；**不是背单词产品**，说明用户会拆「磨耳朵」需求 | 听词模式可吃这部分心智 |

## 3. 按「能力缺口」重排（比按品牌看更有用）

| 用户真实缺口 | 哪些产品最常挨骂 / 做不到 | 墨鱼背词可占位点 |
|--------------|---------------------------|------------------|
| 会认不会拼 | 选择/看图为主的产品 | **听写模式** |
| 会认不会听 | 纯视觉刷词 | **听词（耳机）模式** |
| 复习债劝退 | 不背、部分强 SRS | 计划可调、断签可软着陆 |
| 碎片不能盯屏 | 几乎所有「点选 App」 | 听词少盯屏；Web 标签页中性 |
| 假掌握 | 百词斩图、不背选项 | 默写/听写作验收 |
| 付费羞辱感 | 墨墨上限、Quizlet 订阅 | 核心听写免费可用 |
| 语境不够 | 墨墨偏短释义（亦有人爱） | 释义 TTS + 后续例句可迭代 |
| 小程序轻量 | 多数强产品仍是独立 App | **微信内完成一轮** |

---

## 4. 对推广与产品的简要结论

1. **对外别卷「词库最大 / 算法最玄」**——红海且信任成本高；卷 **听得见、写得出、碎片能用**。  
2. **内容引流**（合成词/听写揭晓）正好打在「假掌握」「不会拼」痛点上。  
3. **视频号→小程序、抖音→Web**：分别吃「轻量打开」与「大屏听写/SEO」。  
4. 产品上警惕抄「高利贷复习」而不给减压阀；付费点尽量放在扩词书/高级音色，而不是「背到一半不能背」。
