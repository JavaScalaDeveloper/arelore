# 墨鱼背词 · 推广计划

> 目标：让「需要背单词 / 听写 / 碎片时间练听力」的用户，能稳定搜到、点到、留下，并在 Web 与微信小程序之间互相导流。  
> 站点：`https://www.arelore.com/word` · ICP：沪ICP备2026055763号  
> 品牌：对外 **墨鱼背词**；小程序名 **背单词**；标签页保持中性（如「墨鱼工作台」），不把「摸鱼」写进公开 SEO。

---

## 1. 定位与卖点（对外口径）

**一句话**：面向碎片时间的英语单词学习工具，支持看词识意、听力跟读与听写默写。

**差异化（相对「只刷列表」类产品）**

| 卖点 | 对外怎么说 | 对内对应能力 |
|------|------------|--------------|
| 听得见 | 戴耳机就能练，少盯屏 | 听词模式 + TTS（词 / 拼读 / 释义） |
| 写得出 | 听写巩固拼写 | 听写模式 |
| 有计划 | 词书 + 每日新学/复习 | 学习计划 |
| 多端 | 浏览器随时开；微信里也能刷 | Web `/word` + 小程序 |

**人群优先级**

1. 备考（四六级 / 考研词汇）——词书与「听写」共鸣强  
2. 上班族碎片时间——「听力 / 少盯屏」共鸣强  
3. 中小学家长代找工具——偏 Web 搜索与小程序搜索  

公开文案避免「摸鱼」；产品内设置可用「听词（摸鱼）」作内部趣味命名。

## 2. 阶段节奏（建议）

| 阶段 | 时间感 | 重点 | 成功信号（示例） |
|------|--------|------|------------------|
| P0 地基 | 当前～2 周 | SEO 可抓取、小程序可搜可分享、核心漏斗可统计 | `/word` 被收录；小程序分享卡片可用；日活有数 |
| P1 冷启动 | 第 2～8 周 | 内容页 + 关键词投放小流量 + 社群种子 | 自然搜索有点击；小程序打开次数周环比↑ |
| P2 放量 | 第 3～6 月 | 词书/场景专题 + 互导闭环 + 复盘投放 | 搜索品牌词「墨鱼背词」有量；Web↔小程序互相导流可测 |
| P3 巩固 | 持续 | 口碑、词书扩展、合规与体验 | 留存与完成计划率；差评率可控 |

不必等「功能全做完」再推广；**先保证打开就能学一轮词**，再边推边补。

## 3. Web 端怎么推广

### 3.1 入口与漏斗

```
搜索/外链 → www.arelore.com/word（落地）→ 登录 → 选词书/计划 → 学习页
```

落地页现状：未登录展示 SEO 文案（模式说明、场景、FAQ）。推广时保证：

- 首屏 3 秒内看清「背单词 / 听写 / 听力」价值 + 登录 CTA  
- 登录后默认进入可学习状态（词书或引导选书），减少空白页跳出  

### 3.2 SEO（站内已有基础，继续加深）

**已具备（对照代码）**

- `wordSeo.ts`：description、keywords、JSON-LD（WebApplication / HowTo / FAQ）  
- `WordDocumentSeo`：title/meta/OG/canonical  
- `index.html` 预写 meta（利于爬虫首屏）  
- `robots.txt` 放行 `/word`；`sitemap.xml` 含 `/word` 及区域路径  

**标签页策略（产品约束）**

- `document.title` / OG title：**中性**（墨鱼工作台），防旁人识破  
- **meta description / keywords / 正文 / JSON-LD**：继续用「墨鱼背词、英语单词、听写…」做收录  

二者不冲突：同事看标签栏是中性名，搜索引擎读的是 meta 与正文。

**P0～P1 站内加强（建议排期）**

| 项 | 做法 | 目的 |
|----|------|------|
| 词书/场景落地页 | 如 `/word` 下只读介绍页：「四级核心词」「通勤听力十五分钟」（可先静态 Markdown→页面） | 长尾词入口，避免只有一个首页 |
| 内链 | 官网首页「外语」→ `/word`；页脚/产品列表互链 | 权重与发现路径 |
| sitemap 扩容 | 每新增公开介绍页就写入 `sitemap.xml` | 加快发现 |
| 结构化数据 | 保持 FAQ；词书页可加 `LearningResource`（有稳定 URL 后再加） | 富摘要机会 |
| 性能与可索引 | 关键文案尽量 SSR/预渲染或保证爬虫能读到首屏 HTML（已有 bootstrap script，专题页同理） | 避免「全靠客户端渲染导致收录差」 |
| Search Console | 绑定 `www.arelore.com`，提交 sitemap，看「墨鱼背词 / 单词听写」等查询 | 用数据迭代标题与 description |

**关键词分层（写作与专题用）**

| 层 | 示例 | 用途 |
|----|------|------|
| 品牌 | 墨鱼背词 | 投放与外链锚文本统一 |
| 功能 | 在线背单词、单词听写、听力背单词、碎片时间学英语 | 首页与 FAQ |
| 场景/考试 | 四级单词听写、考研词汇听力、上班通勤背单词 | 专题页标题 |
| 竞品周边 | 慎用纯品牌词砸钱；内容里自然对比「少刷列表、多听写」即可 | 内容向 |

**外链与收录辅助（低成本）**

- 个人/团队技术博客、掘金/知乎专栏发「听写模式怎么设计」类文章，锚到 `/word`  
- 开源或产品更新说明带正式域名（勿只写 localhost）  
- 百度/必应站长与 Google Search Console 都提交（国内用户双引擎）

### 3.3 Web 投放与内容（有预算再开）

- **信息流/搜索广告**：先小预算测「单词听写」「在线背单词」→ 落地 `/word`，看注册成本  
- **内容**：每周 1 篇场景文（通勤 / 讲座间隙 / 考前冲刺），文末 CTA 登录 Web 或「微信搜：背单词」  
- **邮件/站内**：若已有 Arelore 用户，在官网消息或邮件推一次「外语 → 墨鱼背词」

### 3.4 Web → 小程序导流

在 Web 学习页 / 设置 / 落地页增加固定模块（实现时再开发）：

- 「通勤时用微信刷」+ **小程序码** + 文案「微信搜索：背单词」  
- 同一账号体系下强调：词书进度云端同步（若已打通账号；未打通则先引导「同邮箱/同微信绑定」路线图）

## 4. 微信小程序怎么推广

### 4.1 上架与可被发现（P0）

| 项 | 建议 |
|----|------|
| 名称与简介 | 对外展示名可用「背单词」或带品牌「墨鱼背词」；简介写清：词书、听写、听力、碎片时间 |
| 类目 | 教育 → 在线教育 / 学习工具（以微信后台可选类目为准，注意资质） |
| 搜索关键词 | 后台配置：背单词、单词听写、英语单词、四级词汇等（有字数限制，精选） |
| 隐私与登录 | 微信登录、用户信息协议完善，避免审核驳回断推 |
| sitemap | 工程内 `sitemap.json` 已 allow；上架后关注「微信搜一搜」收录表现 |

### 4.2 分享与裂变（当前缺口，优先补）

代码侧目前缺少 `onShareAppMessage` / `onShareTimeline` 等分享钩子，推广前建议补齐：

| 能力 | 用途 |
|------|------|
| 转发给好友 | 卡片标题如「一起听写这本词书」；path 带词书/邀请参数（若有） |
| 分享到朋友圈 | 适合「打卡感」素材（注意合规，勿诱导分享） |
| 生成海报/小程序码 | 社群、朋友圈长图；Web 落地页也可嵌码 |

冷启动话术示例：「戴耳机就能听写，不用一直盯着屏幕」——不提摸鱼。

### 4.3 流量来源组合

| 渠道 | 做法 | 备注 |
|------|------|------|
| 微信搜一搜 | 优化名称/简介/关键词 + 稳定活跃 | 长期基本盘 |
| 社群 | 考研/四六级/打卡群：管理员同意后发小程序卡片 | 种子用户质量高 |
| 视频号/短视频 | [主线 A](./content-mainline-a.md) 讲解 + [主线 B](./content-mainline-b.md) 朗读；节奏见 [生产手册](./content-production.md)；**视频号→小程序，抖音→Web** | 同片改 CTA；抖音带 UTM |
| 公众号 | 若有公号：菜单或文末「背单词小程序」 | 与品牌文一致 |
| 互推 | 与「考证宝」等同主体小程序互相入口（「外语」「考证」） | 同账号用户复用 |
| 线下/校园 | 打印小程序码（自习室、社团） | 适合考试季 |

### 4.4 小程序 → Web

适合「大屏听写、管理词书、SEO 落地」场景：

- 「我的」页增加「网页版：www.arelore.com/word」  
- 分享文案可带短链（若后续做短链服务）

## 5. 引流总策略（怎么拉新）

按「成本从低到高」：

1. **自然搜索（Web SEO + 微信搜一搜）** — 持续投入文案与专题页  
2. **存量互导** — 官网导航、考证宝 ↔ 背单词、已有用户触达  
3. **内容种草** — 知乎/小红书/B 站：场景向（通勤、听写），主页链到 Web 或搜小程序名  
4. **社群与校园** — 考试季集中推听写/词书  
5. **付费** — 搜索广告、信息流；先小预算验证注册成本再放大  

**统一 UTM / 渠道标记（建议）**

- Web：`?utm_source=zhihu&utm_medium=article&utm_campaign=word_listen`  
- 小程序：scene / query 带 `from=`，服务端或前端打点进 `common_user_daily_visit` 或独立事件表  

没有渠道字段，后面无法判断「哪篇笔记有效」。

## 8. 风险与合规注意

- **商标与名称**：小程序名、简介勿侵犯大厂品牌；「背单词」类通用词可用，品牌强调「墨鱼背词」  
- **教育类目资质**：按微信/应用市场要求准备  
- **隐私**：TTS、登录、日志合规；公开文档勿写密钥  
- **「摸鱼」**：仅产品内趣味文案；广告、SEO、分享卡片一律不用，降低审核与职场传播风险  
- **ICP 与域名**：页脚备案号保持正确；推广链接统一 `www.arelore.com`

## 9. 近期可执行动作（两周内）

1. Search Console / 百度站长：验证域名并提交现有 sitemap
