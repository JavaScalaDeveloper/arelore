# 主线 B · 英语朗读 / 听力条

> 定位：**产量担当**，成本低于主线 A；养完播、关注与「戴耳机听」心智。  
> 渠道同 A：**视频号 → 小程序**；**抖音 → Web**（UTM）。  
> 形态：一张主视觉（或轻推镜）+ 英文字幕 + 朗读；**不做毒鸡汤流水线，不做 MoneyPrinter 整包本地渲染**。

与 [主线 A](./content-mainline-a.md) 搭配：A 打爆款与搜索词，B 填日历、稳更新。

---

## 1. 为什么做 B

| 点 | 说明 |
|----|------|
| 成本 | 静图/轻动效 + 云 TTS + 剪映模板，无本地 GPU 也能日更 |
| 产品对齐 | 直接对应「听力 / 听词」；片中可轻提「听完默写一遍」 |
| 平台 | 完播稳定，适合系列追更；审疲劳低于整段 AI 混剪鸡汤 |
| 导流 | 同 A：简介分流 + 置顶；片尾 2 秒淡 CTA 即可 |

**不做**：空洞励志长文配风景（类型 4 毒鸡汤）；少儿卡通；整屏 App 录屏。

---

## 2. 统一片型（15～30 秒）

| 秒数 | 画面 | 声音 / 字幕 |
|------|------|-------------|
| 0～2 | 系列角标（如「通勤听写 · Day 12」） | 轻 BGM 起或静音进朗读 |
| 2～22 | 固定构图：图在上/全屏；**英文大字幕**居中或底部 | TTS 朗读英文；可跟一行中文小字释义 |
| 22～28 | 可选：单词/短语再单独闪一次（利于听写） | 「暂停，拼写一下」类提示（口语轻） |
| 末 2s | 淡 CTA | 视频号 / 抖音分端文案（同 A） |

**字幕规范**

- 英文为主（听力条的记忆点）；中文释义一行、字号更小  
- 一次只推 **1 句或 3～5 个词**，勿整段散文  
- 语速：偏慢于日常口语，方便跟读（可与产品 TTS speed≈1.0 一致）

**画面规范**

- 一张高质量静图 + 极慢推拉（Ken Burns）足够  
- 图与内容**弱相关即可**（桌面、窗光、通勤虚化），不要图文打架  
- 系列固定同一字幕模板、同一角落 Logo/花字，降低「杂号」感

## 3. 内容子类型（按周轮换）

### 3.1 通勤听写 · 今日 N 词（主推）

- **结构**：3～5 个词，每个：英音 → 拼写字幕停 0.5s → 中文义  
- **选题**：直接从四级/考研/你们词书高频表抽  
- **标题**：`通勤听写 Day12｜5 个易拼错词`  
- **时长**：20～30s  

### 3.2 一句就够（单句精听）

- **结构**：1 句实用英文 + 拆出 1 个关键词加粗  
- **选题**：办公、通勤、预约、礼貌拒绝等成人场景（避开少儿）  
- **标题**：`一句精听｜Could you spare a minute?`  
- **和 A 联动**：句中若有合成/派生词，评论区可「详解见上条合成词」  

### 3.3 听写挑战（互动）

- **结构**：先只出语音（字幕延迟 2～3s 或先打码）→ 再揭晓拼写  
- **标题**：`听写挑战｜这个词你能写对吗`  
- **互动**：评论区置「写下你的拼写」——利于算法与粘性  

### 3.4 易混听写（轻量，每周 1～2）

- 从 A 的易混池拿一对，**只朗读对比、不讲长道理**（道理留给 A）  
- 例：连续读 desert / dessert，字幕稍后揭晓

## 4. 两周与 A 的排期关系

原则：**A 负责「讲清楚」，B 负责「天天有」**。

| 日 | 建议 |
|----|------|
| 周一～五 | 每天 **1 条 B**（通勤听写或一句精听） |
| 每周选 3 天 | 额外或替换为 **1 条 A**（合成/派生等） |
| 周末 | 1 条听写挑战 B，或复用周中数据最好的词重剪 |

两周样本（可与 A 文档排期合并执行）：

| 日 | B 内容 | 备注 |
|----|--------|------|
| D1 | 通勤听写 5 词（含 ice-cream） | 与 A 合成词 01 同日或次日，互相导流 |
| D2 | 一句精听 | |
| D3 | 听写挑战 1 词 | 易混日可对齐 A |
| D4 | 通勤听写 5 词 | |
| D5 | 一句精听 | |
| D6 | 通勤听写（多义词 light 相关句） | 对齐 A 多义 |
| D7 | 休息或听写挑战复盘 | |
| D8～D14 | 重复节奏；词表换下一批 | 固定栏目名不要改 |

## 5. 低成本生产线（无本地 NVIDIA）

```
词表/句子（Excel 或词书导出）
  → 大模型批量出：英文、中文义、标题、封面文案
  → 云 TTS 出 mp3（与产品音色接近更佳，如 Serena）
  → 选图：自有/商用图库；或文生图一张
  → 剪映：套「主线 B」模板（字幕样式锁死）
  → 导出 1080×1920 → 视频号 + 抖音
```

| 步骤 | 工具建议 | 注意 |
|------|----------|------|
| 文案 | 任意 LLM | 一次生成 7 天，减少每日决策 |
| 语音 | 云 TTS（方舟/产品同款链路） | speed 用 1.0，避免变速底噪 |
| 成片 | 剪映 | 不要上 MoneyPrinterTurbo 全流程 |
| 视频大片 | 一般不用 | 仅封面需要动感时再 Seedance 出 3s 环路 |

**单条耗时目标**：熟练后 **10～20 分钟/条**（含导出）。

## 6. 文案与导流模板

**简介（与 A 共用定位句，可加一句）**

- `碎片时间听写 · 通勤 N 词 / 合成词短讲解`  
- 视频号：小程序「背单词」  
- 抖音：`https://www.arelore.com/word?utm_source=douyin&utm_medium=video&utm_campaign=listen_strip`

**置顶评论**

- 视频号：`戴耳机听完 → 点头像进小程序默写`  
- 抖音：`网页版听写 arelore.com/word · 也可点主页链接`

**片尾字幕（2s）**

- 视频号：`头像 · 小程序继续`  
- 抖音：`主页 · 网页版继续`

## 7. 验收

| 指标 | 看什么 |
|------|--------|
| 完播 | B 是否明显高于杂乱长视频 |
| 追更 | 「Day N」是否有人催更 |
| 导流 | 听写挑战条的小程序/Web 点击是否更好 |
| 协作 | A 爆款词是否适合做成次日 B 的「复习条」 |

若 B 完播高但导流弱：加强「暂停拼写」与置顶话术，而不是加长鸡汤。
