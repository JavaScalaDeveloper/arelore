# 考证宝（cert）

刷题 / 备考类产品，与「墨鱼背词」并列，共用 Arelore 用户体系与后台公共能力。

## 客户端

| 端 | 路径 | 说明 |
|----|------|------|
| 微信小程序 | `arelore-client/arelore-client-mini/arelore-client-mini-cert` | Taro + React；刷题、收藏、考试记录等 |
| 管理端 | `arelore-client/arelore-client-web-admin` → 产品「考证宝」 | 题目 / 试卷等管理 |

## 文档待补

- 产品定位与题库范围
- 上架与类目合规要点
- 与 word 的交叉引流策略（可选）
