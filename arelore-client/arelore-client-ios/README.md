# iOS 原生应用

## 子模块

| 模块 | 说明 |
|------|------|
| [arelore-client-ios-base](./arelore-client-ios-base) | Swift 热更新壳：竖屏 WKWebView 打开 `http://www.arelore.com/home` |

## 技术栈

- **语言**: Swift 5
- **开发工具**: Xcode 15+
- **最低版本**: iOS 13.0

## 快速开始

用 Xcode 打开 `arelore-client-ios-base/Arelore.xcodeproj` 并运行即可。
