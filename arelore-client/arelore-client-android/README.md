# Android 原生应用

## 子模块

| 模块 | 说明 |
|------|------|
| [arelore-client-android-base](./arelore-client-android-base) | Kotlin 热更新壳：竖屏 WebView 打开 `http://www.arelore.com/home` |

## 规划技术栈

- **语言**: Kotlin
- **开发工具**: Android Studio
- **最低版本**: Android 7.0 (API 24)

## 快速开始

用 Android Studio 打开 `arelore-client-android-base` 目录并运行即可。
