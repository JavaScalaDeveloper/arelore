# arelore-client-android-prompt

AI 提示词手机端：账号登录、底部「提示词 / 我的」、环境切换、列表筛选与复制 / 打标 / 改状态 / 详情。

## 功能

- **登录**：邮箱+密码 或 用户名+密码（密码以 SHA-256 摘要提交，对齐 Web）
- **底部菜单**：提示词列表 | 个人中心
- **提示词列表**
  - 按标题、发布状态、标签筛选
  - 复制提示词 / 复制全部字段
  - 打标（人工标签多选 + 自定义）
  - 修改发布状态（草稿 / 制作中 / 已发布 / 已下架）
  - 详情弹窗（拉 `/user/prompt/detail`）
- **个人中心**：切换服务端环境（本机 / 测试 / 正式 / 自定义）、退出登录

## 服务环境

| 环境 | API Base |
|------|----------|
| 本机 | `http://10.0.2.2:8081/api`（模拟器访问电脑 localhost） |
| 测试 | `http://test.arelore.com:8281/api` |
| 正式 | `https://www.arelore.com/api` |
| 自定义 | 真机填电脑局域网 IP，如 `http://192.168.1.8:8081/api` |

说明：Android 模拟器里 `127.0.0.1` 是模拟器自己，连不上电脑上的 8081；必须用 `10.0.2.2`。

若以前选过「本机」仍连 `127.0.0.1`，请到设置里重新选一次「本机」并保存环境，或清应用数据。

## 构建

```bash
./gradlew :app:assembleDebug
```

产物：`app/build/outputs/apk/debug/arelore-android-prompt-1.0.0-debug.apk`

## 说明

- 未登录时仅显示登录页；登录成功后进入底部导航。
- 打标 / 改状态走 `/user/prompt/save`，与 Web 列表行内保存字段一致。
